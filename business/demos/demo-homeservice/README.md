# IronOak Home Services — Demo Website

**This is a demo.** IronOak Home Services is a fictional business created as a portfolio example. All contact details, service areas, testimonials, and content are placeholder material.

## Files

- `index.html` — single-page site, all sections
- `styles.css` — mobile-first responsive styles (deep navy + safety amber palette, CSS custom properties)
- `script.js` — mobile hamburger nav (vanilla JS) and dynamic footer year

## Run it

Open `index.html` directly in a browser (`file://`). No build step, no frameworks, no external dependencies.

## Demo disclosures built into the site

- HTML comment at the top of `index.html` marking the business as fictional
- Visible footer line: "Demo website — fictional business created as a portfolio example."
- Testimonials block labeled "Sample layout — placeholder content" with generic placeholder text
- Quote form labeled "Demo form — not connected" (submits via `mailto:` only)
- Contact details use 555 numbers and "78 Demo Road"; license field reads "License #XXX-DEMO (placeholder)"
- Service areas are generic names each tagged "(demo service area)"

## Notes

- No emojis anywhere; inline SVG icons only
- Accessible: skip link, semantic landmarks, labeled form controls, keyboard-friendly nav (Escape closes menu), visible focus states, `prefers-reduced-motion` support
- SEO meta tags included; `noindex, nofollow` set since it is a demo
