# UPDATE SYSTEM — MYRAA AI OS

> Safe, user-consented auto-update. Identity & data are always preserved.

## Architecture

```
RENDERER (about/settings UI)
   │  myraaUpdate.check/download/install/subscribe  (contextBridge)
   ▼
ELECTRON MAIN  (resources/app/electron/updater.cjs)
   │  electron-updater v6 (already installed)
   │  autoDownload=false · autoInstallOnAppQuit=false
   ▼
GITHUB RELEASES  (provider: vishwajeetsrk/JARVIS-AI-OS)
   │  electron-builder publish config (electron-builder.v2.yml)
   ▼
latest.yml (generated by electron-builder) + artifacts + checksums.txt
```

## Behavior

1. **Startup** — silent check ~12s after window load (`scheduleStartupCheck`).
2. **Check moments** — startup, manual (`Check for Updates`), periodic (future).
3. **Manual** — `myraaUpdate.check()` → `myraaUpdate.download()` (user consent) → `myraaUpdate.install()` (`quitAndInstall`).
4. **Never auto-download/install** unless the renderer UI explicitly requests it.

## States

`idle → checking → available → downloading(percent) → ready → updating → done` —
also `up-to-date`, `error {message}`, `disabled` (set `MYRAA_UPDATER_DISABLE=1`).

## Renderer API (preload)

- `myraaUpdate.check()`
- `myraaUpdate.download()`
- `myraaUpdate.install()`
- `myraaUpdate.state()`
- `myraaUpdate.subscribe(cb)` → unsubscribe fn

## Integrity & Safety

- Pubkey verification: **NOT yet configured** — enable electron-updater signature
  verification before production distribution (electron-builder `publish` + updater config).
- Updates come only from GitHub Releases (owner `vishwajeetsrk`, repo `JARVIS-AI-OS`).
- `autoUpdateEngine.cjs` (legacy in-place wiper) is **NOT mounted** (`server.cjs` has no
  route). It now resolves its root from runtime instead of a hardcoded `D:\` path,
  and stays inert until re-audited for safety (raw `xcopy`/`taskkill` = RCE-by-design).
- Update history / rollback: see `latest.json` and `checksums.txt` pipeline in
  `scripts/release.cjs`.

## Channels

Stable (default) · Beta · Development — user-selectable in Settings when the About UI is built.
