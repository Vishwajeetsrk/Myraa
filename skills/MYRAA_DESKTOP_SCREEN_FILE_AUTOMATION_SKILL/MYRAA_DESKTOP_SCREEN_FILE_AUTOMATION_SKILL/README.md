# MYRAA Desktop, Screen & File Automation Skill

## Install
Copy this folder into:

C:\Users\Vishwajeet\Downloads\Skills\

Then register `manifest.json` in MYRAA's skills registry.

## Runtime integrations needed
This skill requires MYRAA to connect to:
- Computer-use / desktop automation provider
- Screen capture + OCR/vision
- Browser automation
- Local filesystem adapter
- Download manager
- ZIP/archive adapter

## Important
The skill is an orchestration specification. Actual screen control, filesystem access,
and browser control must be enabled by your MYRAA runtime and user permissions.
